# Sorriso Ideal

Site de clínica desenvolvido em React.

## Recursos

Menu móvel, seções institucionais e rotação automática de depoimentos.

## Tecnologias

React, JavaScript e Vite. Consulte package.json para as dependências e versões declaradas.

## Executar localmente

Use Node.js e npm compatíveis com as dependências declaradas:

```sh
git clone https://github.com/Felipegaldinos/sorriso-ideal.git
cd sorriso-ideal
npm install
npm run dev
```

Abra o endereço exibido no terminal. `npm run build` gera a versão de produção. `npm run preview` permite visualizar esse build.

## Onde começar no código

- `src/App.jsx` — ponto de entrada para entender o projeto.

## Estado atual

Revise dados de profissionais, depoimentos e contatos antes de publicar para uma clínica real; a interface não comprova um sistema de agendamento.
